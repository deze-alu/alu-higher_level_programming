# Python - Network #0

Exploring HTTP with `curl`: request methods, headers, body parameters and the
responses a server sends back.

## Tasks

| File | Description |
|------|-------------|
| `0-body_size.sh` | Displays the size in bytes of the body of a response |
| `1-body.sh` | Displays the body of a 200 response |
| `2-delete.sh` | Sends a DELETE request and displays the body |
| `3-methods.sh` | Displays the HTTP methods accepted by a URL |
| `4-header.sh` | Sends a GET request with a user id header |
| `5-post_params.sh` | Sends a POST request with an email and a subject |
