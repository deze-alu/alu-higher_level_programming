``2-matrix_divided`` module
===========================

Using ``matrix_divided``
------------------------

Load the function under test:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Every element is divided and rounded to 2 decimal places:

    >>> matrix_divided([[1, 2, 3], [4, 5, 6]], 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The given matrix is left untouched:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Floats are accepted as elements:

    >>> matrix_divided([[1.5, 2.5], [3.5, 4.5]], 2)
    [[0.75, 1.25], [1.75, 2.25]]

A negative divider gives negative results:

    >>> matrix_divided([[2, 4]], -2)
    [[-1.0, -2.0]]

A float divider works as well:

    >>> matrix_divided([[1, 2]], 0.5)
    [[2.0, 4.0]]

A single row and a single element are both valid matrices:

    >>> matrix_divided([[6]], 3)
    [[2.0]]
