Using ``add_integer``
---------------------

Load the function under test:

    >>> add_integer = __import__('0-add_integer').add_integer

Two positive integers are added together:

    >>> add_integer(1, 2)
    3

The second argument defaults to 98:

    >>> add_integer(2)
    100

Negative numbers are handled as well:

    >>> add_integer(100, -2)
    98

    >>> add_integer(-3, -4)
    -7

Zero changes nothing:

    >>> add_integer(0, 0)
    0

Floats are casted to integers before the addition:

    >>> add_integer(100.3, -2)
    98

    >>> add_integer(1.9, 2.9)
    3

A negative float is truncated towards zero, not rounded down:

    >>> add_integer(-1.9, 0)

A float alone still uses the default second argument:

    >>> add_integer(2.3)
    100

Booleans behave like the integers they are:

    >>> add_integer(True, 1)

A large number keeps its precision:

    >>> add_integer(10000000000, 1)
    10000000001
