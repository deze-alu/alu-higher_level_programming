# Python - Network #1

Sending HTTP requests from Python, first with the standard `urllib` package and
then with the friendlier `requests` package.

## Tasks

| File | Description |
|------|-------------|
| `0-hbtn_status.py` | Fetches a status URL with urllib |
| `1-hbtn_header.py` | Displays the request id of a response with urllib |
| `2-post_email.py` | Posts an email with urllib |
| `3-error_code.py` | Displays a body or an error code with urllib |
| `4-hbtn_status.py` | Fetches a status URL with requests |
| `5-hbtn_header.py` | Displays the request id of a response with requests |
| `6-post_email.py` | Posts an email with requests |
| `7-error_code.py` | Displays a body or an error code with requests |
| `8-json_api.py` | Searches a user by letter and reads the JSON answer |
| `10-my_github.py` | Displays a GitHub user identifier |
