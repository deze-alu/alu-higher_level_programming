# Python - Inheritance

Building class hierarchies in Python: subclasses, overriding methods, and the
built-in functions that inspect type relationships.

## Tasks

| File | Description |
|------|-------------|
| `0-lookup.py` | Lists the available attributes and methods of an object |
| `1-my_list.py` | A list subclass that can print itself sorted |
| `2-is_same_class.py` | Checks whether an object is exactly of a given class |
| `3-is_kind_of_class.py` | Checks whether an object belongs to a class family |
| `4-inherits_from.py` | Checks whether an object belongs to a strict subclass |
| `5-base_geometry.py` | An empty base class for geometry shapes |
| `6-base_geometry.py` | A base geometry class whose area is not implemented |
