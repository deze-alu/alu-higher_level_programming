# Python - Classes and Objects

An introduction to Object-Oriented Programming in Python: classes, instances,
private attributes, `self`, the `__init__` method, and properties.

## Tasks

| File | Description |
|------|-------------|
| `0-square.py` | An empty class Square that defines a square |
| `1-square.py` | A Square defined by a private instance attribute size |
| `2-square.py` | A Square that validates the type and value of size |
